# Experiments

This directory contains hands-on experiments conducted during the Airbyte CLI evaluation.

Experiments will be organized by objective and will document:

* Test environment
* Source
* Destination
* Dataset
* Configuration
* Commands executed
* Expected behavior
* Actual behavior
* Execution time
* Errors or warnings
* Observations
* Conclusions

Performance and reliability experiments will be added after the initial environment has been established.
